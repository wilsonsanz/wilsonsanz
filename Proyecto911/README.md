
 Proyecto911

Descripción

El proyecto de la app se centra en buscar solucionar un problema para la ciudadanía ya que muchas veces la línea 911 esta saturada y no hay atención para todos

Características

- Fácil manera de uso.
- Segura y eficiente para reportar emergencias.
- Cuenta con las emergencias principales.

Instalación
Desde un Smartphone Android 5.0+ descargar la siguiente aplicación:
https://github.com/wilsonsanz/wilsonsanz/blob/main/Proyecto911/app-debug.apk
una vez dentro puede crearse un usuario con información personal de vital importancia para atender su emergencia lo antes posible
o usar el usuario defecto usuario: wilsonsanz clave: 1234

repositorio
https://github.com/wilsonsanz/wilsonsanz/tree/main/Proyecto911
